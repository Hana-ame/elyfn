# v2.4.0 — 新增 `/manage/` 开发者可视控制台、Unix Socket 监听及宿主 CLI (`agy`/`pi`/`gh`) 路径支持

> 发布日期：2026-11-27

## 新增（Added）

- **内置开发者可视化管理界面**（[`handlers/manageUi.js`](../handlers/manageUi.js)、[`app.js`](../app.js)）：
  - 在 `GET /manage`、`/manage/` 与 `GET /admin`、`/admin/` 提供零外部依赖的开发者函数控制台 HTML（免密下发空外壳且绝对不含密钥，所有列表、源码读取、上传编译、删除与测试均走原有 `Authorization: Bearer <ADMIN_KEY>` / `EXEC_KEY` 严格鉴权，不影响原有 `GET /` JSON 与接口合约）。
  - 内置 5 套开箱模板：**JS 基础函数**、**TS 类型函数**、**宿主机 `agy` Agent 调用模板**、**宿主机 `pi` Agent 调用模板** 与 **宿主机 `gh` CLI 调用模板**，支持 `PUT` 编译跑 `testCases`、同步/`?async=1` 执行轮询及查看 `/jobs`。
- **Unix Domain Socket 与宿主部署适配**（[`config.js`](../config.js)、[`server.js`](../server.js)）：
  - 新增 `ELYFN_SOCKET`（`ELYFN_SOCKET_MODE`，默认 `0660`），支持在宿主机以零 TCP 端口方式暴露 Unix Socket 给容器 Nginx 反代；启停自动清理残留 `.sock`。
- **CLI 路径安全透传**（[`utils/runInWorker.js`](../utils/runInWorker.js)）：
  - `buildWorkerEnv()` 额外透传非敏感路径环境变量 `AGY_PATH`、`PI_PATH`、`GH_CLI_PATH`，继续严格剥离 `ELYFN_ADMIN_KEY`、`BLUEPRINT_SAVE_KEY`、`GITHUB_TOKEN`、`GH_TOKEN` 等密钥（宿主机部署如需供 `gh`/`agy`/`pi` 使用，可通过 `ELYFN_WORKER_ENV_ALLOW` 按需显式放行）。
