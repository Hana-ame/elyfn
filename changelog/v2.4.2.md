# v2.4.2 — Windows 跨平台兼容（Worker 环境变量大小写与系统变量、`esbuild.cmd`、`cmd` 模板安全封装）

> 发布日期：2026-11-27

## 改进（Changed）

- **Worker 环境变量跨平台白名单与大小写兼容**（[`utils/runInWorker.js`](../utils/runInWorker.js)）：
  - `buildWorkerEnv` 将基础运行时环境变量匹配扩展为大小写无关（兼容 Windows 常见的 `Path`、`SystemRoot`、`ComSpec`、`PATHEXT`、`TEMP`/`TMP`），并在 `platform === 'win32'` 下支持大小写无关匹配 `ELYFN_WORKER_ENV_ALLOW`（如 `USERPROFILE`、`APPDATA`），同时保持对宿主敏感凭据（`GH_TOKEN`、`ELYFN_ADMIN_KEY` 等）的默认剥离。
- **TypeScript 降级编译 `.cmd` 兼容**（[`utils/compileTs.js`](../utils/compileTs.js)）：
  - 在 Windows 下若 `ESBUILD_BINARY_PATH` 指向 `.cmd`/`.bat` 包装脚本则自动启用 `shell: true`。
- **开发者控制台 CLI 启动模板支持 Windows `.exe`/`.cmd`**（[`handlers/manageUi.js`](../handlers/manageUi.js)）：
  - 提取共享 `STARTER_TEMPLATES` 与安全 `execCli` 辅助函数：`agy` / `pi` / `gh` 模板在 `.exe` 与 Linux/macOS 下继续零 shell 直调 `execFile`；在 Windows `.cmd`/`.bat` shim 下拒绝危险控制字符并使用 `cmd.exe /d /s /c` + `windowsVerbatimArguments` 安全执行。

## 验证

- [`tests/elyfn.test.js`](../tests/elyfn.test.js) 新增 Windows 大小写混合环境隔离用例及 `/manage/` 内嵌 `<script>` / `STARTER_TEMPLATES` 语法校验，全量 `npm test`（10/10）通过。
