# v2.3.0 — 后台异步执行与任务状态轮询（`?async=1` + `/jobs/:id`）

- **异步执行模式**：`POST /:folder/:filename?async=1`（或请求头 `X-Elyfn-Async: 1` / `Prefer: respond-async`）立即返回 HTTP `202` 与 `{ ok: true, async: true, jobId, status: "running", statusUrl: "/jobs/<id>" }`，Worker 在后台继续运行，不受短连接超时限制（默认 `ELYFN_ASYNC_TIMEOUT_MS=300000`）。
- **状态轮询接口**：新增 `GET /jobs/:id`（返回 `running` / `completed` / `failed`、`elapsedMs`、`result` / `error`）与 `GET /jobs`（最近任务列表），鉴权级别与 `/catalog` 一致（`EXEC_KEY` 或公开）。
- **任务存储**：新增 `utils/jobStore.js` 管理内存任务生命周期与 TTL/容量淘汰（`ELYFN_JOB_TTL_MS`、`ELYFN_MAX_JOBS`）。
