# v2.3.4 — 修复异步任务并发满载返回 429 及只读查询误淘汰运行中任务

> 发布日期：2026-11-27

## 修复（Fixed）

- **异步执行池满前置拦截**（`utils/runInWorker.js`、`handlers/execute.js`）：新增 `hasWorkerSlot()` 检查；`?async=1` 在并发池已满时立即返回 HTTP `429`，不再先写入任务记录并返回 `202` 后才标失败。
- **读写分离淘汰策略**（`utils/jobStore.js`）：将过期 TTL 清理（`pruneExpiredJobs()`）与容量淘汰（`evictForInsert()`）拆离；`GET /jobs/:id` 与 `GET /jobs` 不再触发容量淘汰，写入淘汰优先清理已完成任务以保护长耗时 `running` 任务。

## 验证

- `tests/elyfn.test.js` 新增并发饱和 `429` 与 `jobStore` 淘汰优先级测试，全部 **9/9** 通过。
