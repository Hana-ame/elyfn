# v2.2 — 只读函数目录 `/catalog`、Worker 环境变量隔离、流式 413 防护与 CI 测试套件

> 发布日期：2026-11-27

## 新增（Added）

- **只读函数目录接口 `GET /catalog`**（`handlers/manage.js`、`app.js`）：仅返回已部署函数的 `folder/name` 与调用路径（不暴露源码），权限与 `POST /:folder/:fn` 保持一致（由 `ELYFN_EXEC_KEY` 控制，未配置则公开；`ADMIN_KEY` 通用），供普通调用方与 Atlas 画布自动拉取函数目录。
- **Worker 环境变量隔离**（`utils/runInWorker.js`、`config.js`）：新增 `buildWorkerEnv()`，创建 `worker_threads` 时仅透传安全基础变量、`ELYFN_FN_*` 前缀变量与 `ELYFN_WORKER_ENV_ALLOW` 白名单，防止同容器内宿主密钥（如 `GITHUB_TOKEN`、`ELYFN_ADMIN_KEY`、`BLUEPRINT_SAVE_KEY`）泄露给函数。
- **自动化测试与 GitHub Actions CI**（`tests/elyfn.test.js`、`package.json`、`.github/workflows/ci.yml`）：新增 5 条基于 `node:test` 的端到端与安全回归用例（上传、`/catalog`、执行、环境变量隔离、热更新失败回滚、504 超时强杀、429 并发限流、流式 chunked 413 拦截、删除），并配置 Node 18/22 矩阵与 Docker 冒烟测试工作流。

## 改进（Changed）

- **常量时间鉴权与 CORS 预检**（`app.js`、`config.js`）：密钥比对改用 `crypto.timingSafeEqual`，在鉴权拦截器前放行 `OPTIONS` 预检请求（返回 `204`），新增 `ELYFN_CORS_ORIGIN`（默认 `*`）支持子域名与跨域前端调用。
- **流式请求体字节计数限制**（`adapter.js`）：新增 `createByteLimitStream()` 实时统计读取字节数，防止 `Transfer-Encoding: chunked` 请求绕过 `Content-Length` 校验突破 413 上限。
- **优雅停机与连接超时保护**（`server.js`）：停机时调用 `server.closeIdleConnections()` 立即释放 Keep-Alive 空闲连接，补充 `headersTimeout`（15s）与 `requestTimeout` 防止慢速连接占坑。
- **文档与配置示例**（`readme.md`、`.env.example`）：同步更新权限说明、测试状态与新增环境变量。
